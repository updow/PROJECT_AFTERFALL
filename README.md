# PROJECT: AFTERFALL

Jogo de sobrevivência 3D em primeira pessoa.

## Identidade do projeto
- Engine: Godot 4
- Linguagem: GDScript
- Estilo visual: Low Poly realista
- Mundo: Rural e urbano
- Infectados: Lentos e rápidos
- Plataforma-alvo: Android ARM64
- Renderizador: Compatibility
